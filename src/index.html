关于 Math Studio

Math Studio

v2.1.0

高级数学函数与复合动画可视化工作台

Math Studio 是一款数学函数与动画可视化桌面软件。集成了高性能 WebGL2 3D 向量图形、SymPy 符号微积分代数内核、任意参数关键帧复合变换与 FFmpeg 60fps 硬件视频编码管线。

核心技术体系
• 3D 视口：Three.js r186 (曲面 / 空间曲线 / Frenet 标架 / 向量场)
• 代数内核：Python 3.13 + SymPy 1.14 (符号求导 / 偏导 / 梯度 / 积分)
• 动画引擎：多参数时间轴 + 任意两帧间复合函数嵌套 g(f(τ))
• 视频管线：FFmpeg 8.1 硬件编码器 (无损 H.264 60fps MP4 渲染)

Math Studio 支持标准数学表达式输入，支持次方符号 ^ 与 **：

三角函数: sin(x), cos(x), tan(x), asin(x), acos(x), atan(x)
双曲函数: sinh(x), cosh(x), tanh(x)
指数对数: exp(x), log(x) (自然对数), log10(x), sqrt(x), abs(x)
特殊函数: sinc(x) = sin(x)/x, sigmoid(x) = 1/(1+e^-x)
常数常量: pi (π ≈ 3.14159), e (自然底数 ≈ 2.71828)
动态参数: t (时间), A (振幅), omega (角频率), phi (相位), R (半径) 等任意自定义参数

任意参数 K 动画原理：

在「关键帧与复合函数动画」面板中，您可以创建任意命名参数。在时间轴的任意位置点击「+ 加关键帧」，即可绑定该时刻的目标数值。

两关键帧间嵌套复合变换 g(f(τ))：
当时间在两关键帧 [t₁, t₂] 之间前进时，标准化进度 τ = (t - t₁)/(t₂ - t₁) ∈ [0, 1]。参数值按复合函数 V(t) = V₁ + (V₂ - V₁) · g(f(τ)) 变换。支持 S 型平滑、阻尼衰减谐振、多重弹跳、陡峭跃迁及自定义嵌套公式！

微积分分析与 3D 可视化：

• 符号求导：一键调用本地 SymPy 计算曲面一阶/二阶偏导数 ∂z/∂x、∂z/∂y 以及梯度矢量 ∇f。

• 切平面 (Tangent Plane)：勾选切平面开关，并在切点输入框指定 (x₀, y₀)，曲面上将实时生成切点法向量与一阶线性近似切平面。

• 梯度矢量场 (Gradient Field)：在曲面网格上直接绘制指向最陡上升方向的矢量箭头。
